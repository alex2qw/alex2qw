## Selected projects

### [ASCII Studio](https://github.com/alex2qw/ASCII-image-converter)

**Rust · Axum · React · TypeScript · Vite** — Full-stack personal project; runs locally.

A browser-based image-to-ASCII editor with black-and-white and colour rendering, custom character ramps and fonts, saved presets, and PNG downloads.

| Original image | Actual colour output |

*Source: Michelangelo, The Creation of Adam (detail), [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Creation_of_Adam_(Michelangelo)_Detail.jpg), public domain.*

- Separates a reusable Rust conversion library from the CLI and HTTP service.
- Checks input dimensions and planned output size before decoding the full image, with server-enforced resource limits.
- Runs CPU-heavy conversion on blocking workers with bounded concurrency; excess requests receive a structured error.
- Debounces editor changes and enables exports only when the preview matches the current image, font, and settings.
- Includes Rust regression tests, frontend component tests, and real HTTP tests that upload images and decode the returned PNGs. A GitHub Actions workflow is configured to run tests, Rust linting, and the frontend build.

This project is helping me understand memory limits, ownership during cancellation, and race conditions across the frontend and backend.
